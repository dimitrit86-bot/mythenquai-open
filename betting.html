So funktioniert’s

1. Einsatz auf Dimitri oder Florian vormerken.

2. Persönlichen 4-stelligen Code unbedingt speichern.

3. Nach Poolschluss wird die Quote berechnet.

4. Mit dem Code Quote öffnen und verbindlich bestätigen oder aussteigen.

5. Falls sich der Pool ändert, kann eine erneute Bestätigung nötig sein.

6. Nach dem Match zeigt das Tool automatisch, wer wem wie viel bezahlt.
